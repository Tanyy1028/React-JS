# 🏥 Appointment Booking App  

A simple React.js application where users can **book an appointment** by filling out a form 📋 and view their submitted details in a card/list view 🗂️.  

---

## ✨ Features  
- 👤 Add patient details (name, phone, gender, age)  
- 📅 Select appointment date  
- 👨‍⚕️ Choose a doctor  
- 📝 Share your problem/issue  
- 📌 View submitted data in **ListView** component (like a card)

## 🚀 Getting Started  

1. **Clone the repo**  
   ```bash
   git clone https://github.com/yourusername/appointment-app.git
   cd appointment-app
````

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the development server**

   ```bash
   npm run dev
   ```

4. Open 👉 `http://localhost:5173` in your browser
