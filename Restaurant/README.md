# 🍽️ PATO Restaurant Website

Welcome to the official repository for **PATO Restaurant's** modern and responsive website, built with **React.js** and **Bootstrap 5**. This project aims to showcase an elegant menu, interactive UI, and smooth user experience for a fictional high-end dining restaurant.

---

## 🚀 Features

✨ Stylish UI with modern glassmorphism and dark/light themes  
📱 Fully responsive design — works beautifully on all devices  
🧭 Sticky navigation for smooth scrolling  
🍕 Menu grid with image overlays and hover effects  
📬 Clean footer with social links and contact details  
🎨 Built with Bootstrap 5 + React  
🌐 Deployed and ready to host

## 🛠️ Setup Instructions

1. Clone the repo

```bash
git clone https://github.com/yourusername/pato-restaurant.git
cd pato-restaurant
````

2. Install dependencies

```bash
npm install
```

3. Start the development server

```bash
npm start
```
