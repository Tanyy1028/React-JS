# 📚 Books App  

A simple **React Books App** that lets you ➕ add, 📝 edit, and ❌ delete books with their authors.  

---
# Video











## ✨ Features
- ➕ Add a new book with **title** & **author**  
- 📝 Edit existing books  
- ❌ Delete unwanted books  
- 📋 View all books in a list  

---

## 🛠️ Tech Stack
- ⚛️ React (useState hooks)  
- 🎨 CSS for styling  

---

📦 Books-App

## 🚀 How to Run
1. 📥 Clone the repo  
   ```bash
   git clone https://github.com/your-username/books-app.git
````

2. 📦 Install dependencies

   ```bash
   npm install
   ```
3. ▶️ Start the app

   ```bash
   npm run dev
   ```

---

## 🎮 Usage

* Type in **Book Title** and **Author** ✍️
* Click **Add Book** ➕ to add it to the list
* Click **Edit** 📝 to update book details
* Click **Delete** ❌ to remove a book
